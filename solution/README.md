# 参考解说明

该参考实现面向 MA-08 离散图算法中的应急物资整批分拨。三个独立挑战分别是（设计卡中的 `axis-1`、`axis-2`、`axis-3`）：

1. 有向简单路径枚举与旅行/风险双约束：对应 `SLA-07`、`THERM-09`，通过逐路径累加并拒绝超限路径验证。
2. 两个发运波次的共享容量、能源预算和整单不可拆分：对应 `CAP-02`、`WAVE-08`、`COOL-10`，每个订单整体占用路径资源。
3. 优先级、开线固定费和稳定字典序：对应 `PRI-01`、`FIX-03`、`TIE-04`，先最大化各优先级接收数，再比较总费用和规范化路径描述。

输入由题面规定的 JSON 契约约束；参考实现先完成严格校验，再枚举有限规模的可行计划，最后通过临时文件、fsync 和原子替换发布。拒收或替换失败会清理临时文件并保留旧目标字节。
